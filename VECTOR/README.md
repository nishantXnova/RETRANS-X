# VECTOR — Versatile Efficient Concept Transformer Optimized Runtime

## Phase 1 Prototype

**Status:** Under active development.  
**Base:** nanoGPT (training harness + dataset loading preserved).  
**Goal:** Prove token-free Concept Atoms + linear SSM cadence without exploding loss.

### Quick Start

1. **Prepare data** (TinyStories in nanoGPT format):
   ```bash
   python data/prepare_tinystories.py
   ```
   Or point `dataset` in `train.py` to any directory with `train.bin` / `val.bin` + `meta.pkl`.

2. **Train:**
   ```bash
   python train.py
   ```

3. **Sample:**
   ```bash
   python sample.py --out_dir=out --checkpoint=ckpt.pt --prompt="Once upon a time"
   ```

   Stream checkpoints are byte-native: prompts are UTF-8 encoded directly and
   generated bytes are decoded as UTF-8 with safe replacement for incomplete
   sequences. Sampling is strictly one-byte autoregressive; `n_predict` is a
   training auxiliary, not an unsafe multi-byte decoder.

4. **Verify the streaming contract:**
   ```bash
   cd VECTOR
   python -m unittest tests/test_stream_contract.py
   ```

   Pure Stream models expose `prefill(prefix)` and `step(byte, state)`. Their
   state contains only each SSM layer's recurrence and causal-convolution
   history, so decode memory does not grow with generated length. Experimental
   retrieval and delta-memory blocks deliberately reject this API until they
   have independently verified carried-state kernels.

5. **T4 optimized runs:**
   ```bash
   # Throughput-oriented 4K training (FP16 Tensor Cores + verified Triton scan)
   python train.py config/stream_t4_4k.py

   # Memory-safe 16K training (activation recomputation enabled)
   python train.py config/stream_t4_16k.py

   # Isolate full-model forward/backward/optimizer performance
   python bench_t4.py --config config/stream_t4_4k.py --output t4_4k.json
   ```

   The benchmark reports synchronized median/p10/p90 step latency, true
   training byte throughput, peak VRAM, model size, GPU identity, and scan
   path. Never compare unsynchronized wall-clock timings.

### Architecture at a Glance

| Component | Replacement | Notes |
|---|---|---|
| `FractalRouter` | nanoGPT `wte` | Byte/Fourier continuous embedding |
| `SaliencyGate` | — | Info-gain pruning → `T_eff < T` |
| `ConceptAddress` | — | `(v, κ)` keyed atoms |
| `SSMBlock` | Transformer attention | Linear `O(T_eff)` scan, 3× per group |
| `AtomAttention` | Transformer attention | GQA + content-addressed `κ`, 1× per group |
| `MoELayer` | MLP | Sparse experts with load-balance aux loss |
| `DualLoss` | Cross-entropy | `L_pred + L_recon + L_budget + L_anchor + L_balance` |

### Success Criteria (Phase 1)

- Convergence on TinyStories with stable dual loss
- `T_eff ≈ T/3` to `T/5` with stable `L_recon`
- Reduced KV-cache VRAM vs standard nanoGPT
