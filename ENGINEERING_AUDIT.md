# RETRANS-X Engineering Audit — accuracy-first, non-transformer

## Decision

Do not scale the current configurations or claim efficiency yet. The shortest
path to a substantially better system is a stateful, fused, hierarchical
recurrent byte model: no attention, no vocabulary tokens, O(T) training work,
and O(1) persistent inference state per layer.

Every proposed improvement must beat a fixed baseline on a frozen,
compute-matched scoreboard. Parameter count and a CPU latency slope are not
evidence of superiority.

## Architecture

### Base SSM

`parallel_ssm_scan` materializes `a_vec`, `b_vec`, and all states in
`(B,T,H,N)` (`VECTOR/model.py:104-114`). This is activation-bandwidth heavy.
Use one fused selective scan that computes transition, injection, update, and
output together. Store chunk boundaries only and recompute inside chunks for
backward. Initialize diagonal timescales log-uniformly; all modes currently
start identically through zero-initialized `A_log`.

### Long memory

Sliding windows are attention and have O(T*W) bandwidth. Static global tokens
are not document-addressable. A practical no-attention alternative is one
upper-layer, low-rank delta fast-weight memory: normalized keys, input-gated
decay/write rates, FP32 state accumulation, and a fused carried-state kernel.
It should be added only after the plain SSM's state API works.

### Byte interface

Bytes are universal, but consume several times more positions than BPE. Keep
raw UTF-8 at the interface, while adding a causal continuous 2x/4x latent
patcher internally. Preserve a byte-rate residual route for spelling, code, and
Unicode. These must remain learned continuous states—not a vocabulary—and must
be ablated against an equal-FLOP byte-only model.

### Multi-horizon objective

Keep next-byte cross entropy primary. Apply decayed auxiliary horizon weights,
for example `[1.0, .35, .15, .05]`, and report every horizon separately. The
current equal weighting gives farther horizons fewer labels but equal influence
(`VECTOR/model.py:623-630`). Never claim 4x decode speed without a separately
trained speculative/block decoder and acceptance test.

### Correctness hazards

- The Delta block calls `LayerNorm` “RMS-ish” (`model.py:425`); LayerNorm
  subtracts the mean. Use actual RMSNorm or correct the claim.
- StreamR's segment-memory padding is left-sided while its validity mask is
  right-sided (`model.py:332-342`); non-divisible sequence lengths need tests.
- Run recurrent state in FP32; projections may use BF16/FP16 only after a
  tolerance-tested mixed-precision check.

## Replace the benchmark

`bench_long_context.py:42-44` rebuilds GPT at each context length, changing
its positional-embedding parameter count. It measures CPU forward only and
does not measure training cost, memory, prefill, or decode.

The replacement matrix must record separately:

1. CPU reference correctness and GPU production throughput.
2. Forward, backward, optimizer, prefill, and one-byte decode.
3. Peak memory, activation memory, and persistent decode-state bytes.
4. A fixed checkpoint/architecture at every context length.
5. Median, p10, p90 latency with synchronized warm runs and hardware versions.
6. Equal-parameter, equal-training-FLOP, and equal-wall-clock comparisons.

## Build order and gates

### Phase 0: trustworthy baseline

Repair sampling, byte I/O, checkpoints, one-byte generation, document splits,
and an evaluation harness. Add loss-alignment, causality, finite-gradient,
save/load/sample, and UTF-8 tests.

**Gate:** a 0.5–2M baseline trains, resumes, samples valid UTF-8, and reports
reproducible BPB with confidence intervals.

### Phase 1: cheap streaming

Add `prefill`/`step` to plain SSM. Implement a fused chunked scan and compare
forward/backward with a simple reference over dtypes, shapes, chunks, and a
nonzero initial state.

**Gate:** stepwise logits match full forward within tolerance; decode work and
state are constant as prefix length grows.

### Phase 2: accuracy without attention

Add continuous multi-rate byte patches, then one fused low-rank delta-memory
block. Ablate base, patches, memory, and both under identical compute.

**Gate:** each retained component improves a predefined long-context or
retrieval slice without exceeding its overall BPB regression budget.

### Phase 3: scale validated mechanisms only

The existing CompreSSM and ES-SSM files are toy research spikes, not integrated
production code. Attempt state-rank scheduling only with validation guards and
reversible checkpoints after the baseline is stable.
